\# AttendVision



\## Smart Attendance System Using Face Recognition



AttendVision is a smart attendance management system designed to automate classroom attendance using face recognition and a structured teacher, student, and administrator workflow.



\## Project Overview



The system is designed to reduce manual attendance work and provide an organized platform for managing students, teachers, classes, schedules, and attendance records.



\### Main Modules



\- Student Management

\- Teacher Management

\- Admin Management

\- Face Recognition

\- Attendance Marking

\- Class \& Schedule Management

\- Attendance Reports



\## System Workflow



\### Student



1\. Student registration

2\. Face data registration

3\. Face recognition login

4\. View attendance

5\. View attendance history



\### Teacher



1\. Teacher login using face recognition

2\. Teacher dashboard

3\. View assigned classes

4\. Schedule/select class

5\. Start attendance

6\. Camera scans students

7\. Faces are recognized

8\. Attendance is automatically marked

9\. Attendance summary is generated

10\. Reports can be viewed



\### Admin



1\. Admin login

2\. Admin dashboard

3\. Manage teachers

4\. Manage students

5\. Manage classes

6\. Manage schedules

7\. View system attendance records
